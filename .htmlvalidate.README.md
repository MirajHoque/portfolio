# Why these validator rules are off

- **no-redundant-role** — every list styled with `list-style: none` also carries
  `role="list"`. Safari and VoiceOver strip list semantics from such lists, so the
  explicit role is what keeps them announced as lists. Redundant per the spec,
  necessary in practice.
- **prefer-native-element** — the experience timeline is an ordered `<ol>` carrying
  `role="list"`; the rule misreads that as a `<ul>` in disguise.
- **no-inline-style** — the 404 page uses a handful of one-off inline styles rather
  than shipping selectors that appear on a single page.
- **require-sri** — nothing is loaded from a third-party origin, so there is no
  subresource to pin.
- **void-style** — self-closing void elements are a formatting preference, not a defect.
